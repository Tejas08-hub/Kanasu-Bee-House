Kanasu Bee House
A Hybrid Acoustic–Vision AI Platform for Smart Apiculture

3rd Runner-Up — Design and Innovation Clinic 2026, CMTI Bengaluru

Overview

Kanasu Bee House is an AI-driven beehive monitoring system that combines acoustic analysis, computer vision, and IoT to enable real-time health assessment of beehives.

The system moves beyond traditional sensor-based monitoring by integrating multi-modal intelligence (sound + image) to provide actionable insights for beekeepers.

Key Features
AI & Analytics
Acoustic machine learning using RMS-based feature extraction
Image analysis using Convolutional Neural Networks (CNN)
Hybrid decision system combining audio and visual outputs
Bee Health Score generation for simplified interpretation
Web Dashboard
Real-time data monitoring
Graphical analytics and visualization
Bee Scan AI for instant health detection
Digital health reports and health cards
Chatbot support for users
Honey production calculator
Learning Centre for educational insights
IoT System
ESP32-based embedded system
DHT22 (temperature and humidity)
MQ135 (gas/air quality sensor)
Load cell with HX711 (weight monitoring)
RTC module (time tracking)
OLED display for local output
Buzzer and LED for alerts
Cloud & Deployment
Firebase for real-time database management
Render for deployment of acoustic and image ML models
Web interface built with HTML, CSS, JavaScript, and Chart.js

Workflow
Sensors collect real-time environmental and hive data
Acoustic signals are processed using ML models
Images are analyzed using CNN models
Outputs are fused to generate a Bee Health Score
Results are displayed on the web dashboard
Alerts and insights are provided to the user
